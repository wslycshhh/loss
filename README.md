# loss

离线运行的汽车 SerDes 通道预算工具，面向整车显示屏工程师，兼顾摄像头。

## 使用

需要 Node.js 22.12+ 或 24+。克隆仓库后：

```sh
npm ci
npm test
npm run dev
```

浏览器打开终端显示的本地地址。生产构建：

```sh
npm run build
```

- `dist/index.html` 和 `dist/assets/`：交给任意内网静态 Web 服务，支持子路径部署。
- `dist/offline.html`：包含脚本、样式和公开规则的单文件，可复制到没有 Node 和互联网的电脑。文件模式的具体浏览器行为需在目标企业环境验收；受管浏览器可能禁止本地 HTML 或下载。
- 网页无 CDN、后台、账号、遥测或运行时 API；导入文件不上传、不写浏览器持久存储。

Windows 本机预览可在完成安装/构建后双击 `Start-Loss.cmd`，并保持终端窗口打开。`127.0.0.1` 指浏览器所在电脑；临时预览停止后该地址会连接失败，它也不是 GitHub 托管的网址。

公司电脑不能访问外网时，可通过批准的传输方式接收已构建的离线包，无需在公司电脑访问 GitHub/npm。浏览器允许本地 HTML 时直接打开 `offline.html`；禁止本地网页时由 IT 将产物部署到内网静态服务。详见部署说明。

## 功能

- PCLK 默认来自 FOG / 模组规格书；也支持 active 分辨率估算、完整时序和像素/时钟换算。芯片支持范围仅用于校验。
- 分别计算有效画面净载荷、PCLK 口径视频数据率、每条物理通道线速、总线速、符号率和 Nyquist。
- 输出视频接口路数与 SerDes 物理通道数独立，前者不会让高速线速减半。
- IL / RL 分段掩码、频段内查询及曲线；不外推、不加和回损，插损分配须先确认参考面和厂家适用条件。
- LEONI、天信、Caleb 三类真实裸线样本及对插敏感性假设。品牌数据未知时明确标为 TBD，跨介质不比较裕量。
- 本地 JSON 规则导入；严格白名单与数值校验，不执行表达式；失败保留原状态。
- Touchstone v1 `.s2p/.s4p`，RI/MA/DB、端口映射确认、差分换算及实测频点比较。不支持 v2、噪声参数或阻抗重归一化。
- 分别导出 SI 设计要求 JSON/CSV 和候选线束参考 JSON，另可浏览器打印为 PDF。

## 当前型号边界

| 规则 | 已实现 | 限制 |
| --- | --- | --- |
| TI DS90UB947-Q1 → DS90UB948-Q1 | 35-bit、单/双物理链路及 PCLK 范围 | 未取得连续 IL/RL 掩码；OpenLDI 时钟须按实际配置核对 |
| ADI GMSL2 协议族 | 3/6 Gbps 固定链路、同轴/STP 通道掩码 | 具体器件搭配和模式支持需另核验，协议族规范不等于型号兼容认证 |
| 慷智公开产品、TI DS90UB933-Q1 摄像头 | 来源与能力说明占位 | 具体物理速率/损耗未确认时保持 TBD |
| 本地授权规则 | 数据驱动速率与数值掩码 | 未核验数据仍为候选，不能升级为正式验收结论 |

来源、修订、频段、公式与未决项见 [SOURCES.md](docs/SOURCES.md) 和 [OPEN_QUESTIONS.md](docs/OPEN_QUESTIONS.md)。

## 隐私与发布边界

供应商非公开资料必须留在本仓库目录之外，通过文件选择器在本地加载。不要把原文、截图、私有规则、内部报告放进工作树，即使已被忽略。公开测试只用合成数据或已核验公开数值。导出报告可能包含当前项目输入及内部限值，请按其可见级别分发。

发布前运行 `npm run audit:public`；也可传入仓库之外的授权数据文件路径进行本地敏感标记比对，扫描不会输出其数值。扫描覆盖源码、构建产物及已存在的 Git 历史；扫描是发布复核的一部分，不能替代人工检查。

## 工程说明

原生 JavaScript ESM + Vite，无运行时第三方依赖。计算、导入、线束估算和实测解析分别使用纯函数；Node 原生测试。构建仅扫描本仓库，不读取外部私有输入。部署说明见 [DEPLOYMENT.md](docs/DEPLOYMENT.md)，规则格式见 [RULE_PACKS.md](docs/RULE_PACKS.md)。
